# Functionalities

- API REST para empresas, usuarios, canales, contactos, conversaciones y mensajes.
- Adaptadores de canal con una interfaz común (recibir, normalizar, enviar).
- Webhooks de Meta, Telegram y Discord; lector IMAP y envío SMTP.
- Bandeja unificada en React con lista de conversaciones, filtros por canal/estado/agente y vista de chat en tiempo real (WebSocket).
- Panel de administración de la empresa: canales, agentes, horarios, respuestas rápidas.
- Tablero de métricas.
- Autenticación con JWT y control de acceso por rol y por empresa.
